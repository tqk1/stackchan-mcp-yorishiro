## 設計判断（HTML-only 境界）

フル案には「**思考中（Hermes処理中）**の可視化」が含まれていたが、gateway 調査で **`voice_turn_active`/`STATUS_THINKING` は `/control/status` に公開されていない**ことが判明（`http_server.py:177-203`）。これを表示するには gateway へのフィールド追加（→ コミット＋pytest）が必要で、「フェーズ5＝dashboard.html のみ」の `/clear` 境界を越える。

ユーザー判断で **HTML-only を維持**。状態ピルは既存エンドポイントで取れる **接続（`esp32_connected`）＋録音（`/control/audio_level.recording`）** のみで構成。思考中表示は後日の別タスクに送った。

## 用語メモ（学習用）

- **状態ピル**: ヘッダーに常駐する小さなバッジ。接続/録音という「今の状態」を一目で示す。フル案の「状態インジケーター充実」の HTML-only での実体。
- **`.ctl-toggle`/`.pad-body` idiom**: フェーズ4(首パッド)で確立した自前の折りたたみ機構。`classList.toggle('open')` で開閉、`▶`/`▼` の chevron を回転。今回 LED 色設定にも**同じ機構を再利用**（native `<details>` を新規導入せず、既存パターンに乗せた）。
- **Apple HIG 44px**: タッチ操作の推奨最小ターゲットサイズ。指で正確に押せる下限の目安。
- **HTML-only 境界**: dashboard.html は git 管理外で編集即反映＝**コミット・flash 不要**。gateway/firmware に触れた瞬間この性質が消える（コミット＋pytest＋検証ゲートが必要）ので、フェーズ5 はこの境界の内側に収めた。
